Audit Runner Pentesin

Dua masalah terverifikasi diperbaiki: output lanjutan shell pada jalur bawaan dan pesan penyelesaian penilaian yang menyesatkan. Perbaikan tidak mengubah scan lama menjadi penilaian lengkap.

Ruang lingkup dan bukti

Database aktivitas menunjukkan command recon berulang kali mengembalikan sesi non-TTY disertai peringatan bahwa output berikutnya hilang. Polling tidak menyediakan hasil yang diharapkan. Rekaman proxy menunjukkan homepage HTTP 200; kegagalan mengambil output bukan bukti target tidak terjangkau. Audit mencakup wrapper shell, penyelesaian scan, dan tes terkait. Tidak ada trafik pengujian baru ke target eksternal.

Temuan 1: output terminal hilang

Dampak: agent kehilangan hasil recon, mengulang command, lalu mencatat pekerjaan belum selesai.

Penyebab: _wrap_exec_command membiarkan mode non-TTY saat argumen TTY dihilangkan. Output lanjutan jalur tersebut tidak dapat diandalkan untuk polling; kode sudah memperingatkan keterbatasannya.

Perbaikan: pentesin/agents/factory.py menetapkan tty=true hanya bila argumen tidak diberikan. Command yang masih berjalan dapat dipoll dengan write_stdin. Pilihan eksplisit tty=false tetap dihormati dan peringatannya dipertahankan.

Batas: ini memperbaiki jalur umum, bukan implementasi ulang polling non-TTY. TTY dapat menggabungkan stream atau mengubah buffering/format output.

Temuan 2: penutupan disebut sukses meski belum lengkap

Dampak: respons finish_scan menyebut sukses meski semua cakupan masih needs_follow_up. Instruksi tool sebelumnya meminta penilaian positif ketika nol kerentanan ditemukan.

Perbaikan: pentesin/tools/finish/tool.py mengembalikan assessment_complete=false dan pesan Scan ended with incomplete coverage; follow-up is required bila ada peringatan cakupan atau gap. Tanpa report state, kelengkapan dinyatakan tidak diketahui. Instruksi kini melarang menyamakan nol temuan dengan target aman dan meminta pemulihan hambatan yang dapat diatasi sebelum finishing.

Semantik: success=true dan scan_completed=true tetap berarti operasi penutupan berhasil. assessment_complete menyatakan kelengkapan cakupan tercatat, bukan jaminan tidak ada celah. Pengujian terhalang tetap boleh diakhiri secara jujur, tanpa memaksa pengujian tanpa akhir.

Batas integrasi: status lifecycle/dashboard completed dan format laporan tersimpan tidak dirombak. Field baru berada pada respons tool; audit ini tidak mengklaim migrasi seluruh status database.

Verifikasi

  • 133 tes terarah lulus: shell adapter, finish coverage, ledger/report/artifact coverage, parameter tool, dan worker web.
  • Docker nyata lulus: printf before; sleep 1; printf after, yield awal 1 ms. Output awal before; polling mendapatkan after, exit code 0. Sandbox uji dibersihkan.
  • Tes mencakup default TTY, mode non-TTY eksplisit, command selesai, batas output, cakupan lengkap/tidak lengkap/tanpa ledger.
  • Review terarah tidak menemukan defect actionable pada perubahan default TTY dan kelengkapan penilaian.

Penggunaan setelah perbaikan

  1. Restart worker agar wrapper dan instruksi tool baru dimuat.
  2. Lanjutkan scan dengan instruksi spesifik atau buat scan lab baru. Output yang sudah hilang tidak dipulihkan otomatis.
  3. Agent harus mempoll command yang masih berjalan memakai ID sesi yang benar.
  4. Tinjau ulang seluruh needs_follow_up; nol temuan bukan bukti aman.
