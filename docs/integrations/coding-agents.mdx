pentesin is built to be driven by AI coding agents. Install the official agent skills and your agent knows how to run pentests, remediate findings, and wire pentesin into CI.

## Install the Skills

Works with any agent that supports the open [SKILL.md standard](https://agentskills.io) — Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and dozens more:

```bash
npx skills add Ghanott/Pentesin
```

| Skill | What your agent learns |
|-------|------------------------|
| `penetration-testing-with-pentesin` | Run headless scans against code, URLs, domains, or IPs — self-hosted CLI or managed cloud — with budget caps, and read the results |
| `managed-pentesting-with-pentesin` | Drive a pentesin-compatible cloud relay over REST — no local Docker or LLM key needed |
| `fix-security-vulnerabilities-with-pentesin` | Triage findings, fix root causes, and re-run pentesin to verify each fix |
| `ci-security-scanning-with-pentesin` | Add PR security scanning to GitHub Actions or any CI (self-hosted CLI or a relay you operate) |
| `application-security-testing` | Assess a whole product: choose the right test for each asset, then rank the findings into one remediation plan |
| `web-app-penetration-testing` | Black-box pentest of a live web app or staging site — scope, credentials, and multi-account access-control testing |
| `api-security-testing` | Test a REST/GraphQL API against the OWASP API Security Top 10 — schema-driven enumeration, BOLA/IDOR, authz |
| `owasp-top-10-testing` | Systematic OWASP Top 10 assessment with honest per-category coverage |
| `find-security-vulnerabilities-in-code` | White-box security review of a repo or working tree, with exploits to confirm findings |

Install a single skill with `npx skills add Ghanott/Pentesin --skill penetration-testing-with-pentesin`, or use one without installing:

```bash
npx skills use Ghanott/Pentesin@penetration-testing-with-pentesin | claude
```

## Two ways to run — self-hosted or managed

Both use the same engine and produce the same validated findings and SARIF, so agents can pick per situation or combine them:

- **Open-source CLI (self-hosted)** — runs locally in a Docker sandbox with your own LLM key. Free, fully local, air-gap capable. Best for local dev loops and full control.
- **Managed cloud** — drive it with the `pentesin cloud` CLI (every REST operation has a `pentesin cloud <resource> <verb>` command) or the REST API directly. This fork ships no hosted relay: point `PENTESIN_APP_URL` at a compatible deployment you operate before using `pentesin cloud login`.

## Agent-Friendly Interfaces

Everything an agent needs is machine-readable:

- **Headless CLI** — `pentesin -n` runs without the TUI and exits with `0` (clean), `1` (error), or `2` (vulnerabilities found).
- **Cloud CLI** — `pentesin cloud` prints JSON when stdout is not a terminal (or with `--json`), never prompts without a TTY, and exits with `0` (success), `1` (error), `2` (usage), `4` (authentication required), or `5` (payment required). Credit top-ups pay the Stripe machine-payment challenge with an agent wallet (`pentesin cloud billing topup --credits N --yes`). Account setup also runs from the CLI: `pentesin cloud workspaces list|create|use`, `pentesin cloud org members invite`, `pentesin cloud billing subscribe`, `pentesin cloud billing portal`, and `pentesin cloud integrations install github`. The last three print a hosted link the user opens to finish the payment or approve the installation.
- **REST API** — a compatible relay exposes scans, vulnerabilities, assets, PR reviews, schedules, and webhooks under a bearer-token API. This fork ships no hosted relay; set `PENTESIN_APP_URL` to one you operate.
- **Structured results** — every run writes `vulnerabilities.json`, `vulnerabilities.csv`, `findings.sarif` (SARIF 2.1.0), and per-finding Markdown under `pentesin_runs/<run-name>/`; the cloud exposes the same as JSON plus SARIF export.
- **Budget controls** — `--max-budget` and `--max-turns` give agents hard cost/time caps.
- **`AGENTS.md`** — the [repository's agent guide](https://github.com/Ghanott/Pentesin/blob/main/AGENTS.md) with a quick reference.
- **Docs** — the documentation sources live at [docs](https://github.com/Ghanott/Pentesin/tree/main/docs); every page is a Mintlify `.mdx` file you can read directly.

## Example Prompts

Once the skills are installed, prompts like these just work:

```text
Pentest this repo with pentesin (quick mode, $10 budget) and summarize the findings.
```

```text
Fix all critical and high findings from the last pentesin run, then re-scan to verify.
```

```text
Add pentesin security scanning to our GitHub Actions so every PR gets tested.
```
